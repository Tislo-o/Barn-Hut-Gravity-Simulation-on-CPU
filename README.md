Set GENERATE_PNGS and RENDER_ON_WINDOW either to true or false depending on your wish.

-If GENERATE_PNGS = true, the program will generate pngs images of each frame in a frame folder at in the same folder as your .exe (make sure to create the frame folder beforehand otherwise it will complains)

-If RENDER_ON_WINDOW = true, the program will open an SFML window on full screen mode. You can move around by dragging and zoom with your mousewheel. You can display the boxes needed for Barn-Hut approximation by pressing your spacebar. If the simulation is too slow for your liking, you can lower N or increase THETA (though the Barn-Hut will become visible).
